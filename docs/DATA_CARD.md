# Data card

## Current data: template fixtures only

`data/fixture` is generated by `switchboard_inference.data.build`, with `provenance: template_fixture` and `reportable: false`.

| Property | Value |
|---|---|
| Source | Hand-written templates with seeded slots, for pipeline tests |
| Tenants | Five fictional businesses |
| Language mix | Target 40% English, 30% English + isiZulu, 20% English + Afrikaans, 10% all three |
| Code-switching | Single fragments inserted into English. Far simpler than real speech. |
| Noise | Guessed text noise, not measured from ASR |
| Review | None |

**Known flaw:** templates cross splits, because there are too few to hold out. Fixture scores are inflated, so they test the pipeline and say nothing about any model.
